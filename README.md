# InteractiveHelloin

Веб-приложение на Django для хэллоуинского мероприятия: ведущий управляет интерактивами и начисляет очки, участники подключаются по коду и следят за статистикой.

## Запуск локально

Требуется Python 3.12+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000/. Администратор Django (`is_staff`) получает панель ведущего по адресу `/host/`. Создавайте ведущего через `createsuperuser` или отметьте `is_staff` для существующего аккаунта в `/admin/`. Пароли хранятся средствами Django с хешированием; включена минимальная длина 12 символов.

## Развёртывание на Render (бесплатно)

В проекте уже есть всё нужное: `render.yaml` (Blueprint), `build.sh`, `Procfile`, `.gitattributes`.

1. Залейте проект в GitHub (см. раздел «Подготовка к GitHub» ниже).
2. Зарегистрируйтесь на https://render.com (удобно войти через GitHub).
3. **New → Blueprint** → выберите репозиторий. Render прочитает `render.yaml` и создаст:
   - Web Service `interactive-helloin` (Python, бесплатный тариф);
   - базу PostgreSQL `helloween-db` (бесплатный тариф).
4. Render попросит заполнить две переменные — это аккаунт ведущего:
   - `DJANGO_SUPERUSER_USERNAME` — логин (например, `host`);
   - `DJANGO_SUPERUSER_PASSWORD` — надёжный пароль.
   Ведущий создаётся автоматически при каждой сборке командой `python manage.py ensure_superuser`
   (на бесплатном тарифе нет Shell, поэтому `createsuperuser` вручную не выполнить).
   Чтобы сменить пароль ведущего — измените переменную в **Environment** и сделайте **Manual Deploy**.
5. Нажмите **Apply** и дождитесь сборки (5–10 минут). Сайт откроется по адресу вида
   `https://interactive-helloin.onrender.com`.

`DJANGO_SECRET_KEY` Render генерирует сам, адрес сайта автоматически попадает в `ALLOWED_HOSTS`
и `CSRF_TRUSTED_ORIGINS` через переменную `RENDER_EXTERNAL_HOSTNAME`.

### Особенности бесплатного тарифа

- Сервис «засыпает» после ~15 минут без запросов; первое открытие после сна занимает до минуты.
  Перед мероприятием просто откройте сайт заранее.
- Бесплатная база PostgreSQL удаляется через 30 дней после создания — для разового праздника этого хватает.
  Если нужны результаты надолго, перед удалением выгрузите их через админку или перейдите на платный тариф.
- Если в аккаунте Render уже есть бесплатная база, вторую создать не получится — удалите старую
  или подключите существующую, вписав её URL в `DATABASE_URL`.

Включите двухфакторную защиту аккаунта Render/GitHub и храните секреты в переменных окружения, не коммитьте `.env`.

## Как играть

1. Ведущий входит под staff-аккаунтом и создаёт событие на `/host/`.
2. Участники сканируют QR-код события, регистрируются с обязательным согласием, затем вводят код события на главной странице.
3. Ведущий создаёт интерактивы и начисляет очки нужному участнику. Таблица обновляется при перезагрузке.
4. Ведущий проверяет результаты, ставит флажок подтверждения и вводит `ЗАВЕРШИТЬ`. Событие закрывается, итоговый победитель фиксируется по сумме очков.

## Подготовка к GitHub

Создайте пустой репозиторий GitHub и выполните в этой папке:

```bash
git init
git add .
# проверьте, что в списке нет .venv, .idea и db.sqlite3:
git status
git commit -m "Initial Halloween interactive app"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Не добавляйте в репозиторий базу данных, `.env`, `SECRET_KEY` или пароли.
